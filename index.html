09

Banking Knowledge Copilot v3 — RAG API with Automated Document Sync

Internal tool — CIB Contact Center
New · n8n · RAG

The challenge

The first copilot answered from a manually maintained Google Sheet. As product and policy documents changed, keeping the knowledge base current by hand was slow, and an outdated answer during a live call is worse than no answer.

The solution

Rebuilt as two connected n8n workflows. A sync pipeline, run manually or on a schedule, reads files from Google Drive, checks them against a ledger and plans what to add or remove. It extracts text from spreadsheets, CSVs, PDFs and text files, splits it into chunks and embeds it with OpenAI into a Supabase vector store. Each file is staged first and applied through an RPC call, so a failed run does not leave the knowledge base half-updated. A chat API workflow exposes the assistant through a webhook: an AI agent with memory retrieves from the vector store and returns the answer.

n8nGoogle DriveSupabase Vector StoreOpenAI EmbeddingsAI AgentWebhook APIJavaScript
Business value: document updates reach the assistant without manual re-uploading, and removed files stop appearing in answers, so agents work from current material.
Real n8n workflow screenshot — sync pipeline (top) and chat API (bottom)
10

Old Money AI Commerce Assistant — One Knowledge Base, Three Channels

Personal automation project
New · n8n · Gemini

The challenge

Customers ask about products, orders and policies on whichever channel they prefer, and a small brand cannot staff every channel around the clock or keep answers consistent across them.

The solution

A Google Drive trigger picks up the business sheets (Customers, Products, Orders, Policies/FAQ), extracts and merges them, and indexes them into a Chroma vector store with Gemini embeddings. Three channel workflows share that one knowledge base: WhatsApp, website chat and Telegram. Each runs a Gemini-powered AI agent with memory that retrieves answers from the store and logs or updates rows in Google Sheets.

n8nGoogle GeminiChroma Vector StoreGoogle DriveGoogle SheetsWhatsAppTelegram
Business value: one knowledge base to maintain instead of three, and the same answer whichever channel the customer uses.
